# Orna Helper（Android 自動化外掛範例）

一個以「無障礙服務（Accessibility Service）模擬點擊」＋「MediaProjection 螢幕擷取」＋「色塊判讀」為基礎的 Android 遊戲自動化範例專案：偵測 HP/MP 血條百分比，低於門檻自動點擊藥水按鈕；偵測「是否有敵人」指示區，自動點擊攻擊按鈕，無敵人時點擊「移動」座標尋找下一個目標。

## ⚠️ 使用範圍（請務必遵守）

**這個工具只設計給你自己完全掌控、允許自動化操作的私有／單機測試環境使用**（例如你自架的私服、本機模擬的遊戲邏輯）。

**請勿**將它用於：
- 連線任何官方伺服器、正式服務，或任何服務條款禁止外掛／自動化操作的線上遊戲——這通常會違反服務條款並導致帳號被封鎖，也會破壞其他玩家的遊戲體驗。
- 任何你沒有明確授權自動化的系統。

工具本身完全在裝置端運作（讀取畫面像素、模擬點擊），不會連線任何伺服器，也不包含任何針對特定遊戲伺服器協議的破解或逆向邏輯——它是通用的「看畫面、按按鈕」自動化框架，具體行為完全取決於你如何校準。

## 架構

```
app/src/main/java/com/ornahelper/autoplay/
├── data/
│   ├── Models.kt            # BotConfig / ScreenRect / CalibratedRegion 等資料模型
│   └── ConfigRepository.kt  # 設定的 JSON 持久化（SharedPreferences）
├── engine/
│   ├── BarReader.kt         # 用色彩距離判讀血條百分比 / 區域是否變化
│   └── BotEngine.kt         # 主迴圈：讀血條 → 判斷是否補藥／攻擊／移動
├── service/
│   ├── OrnaAccessibilityService.kt  # 只做一件事：dispatchGesture 模擬點擊
│   └── OrnaBotService.kt            # 前景服務：畫面擷取、懸浮控制面板、校準精靈、驅動 BotEngine
└── ui/
    ├── MainActivity.kt          # 權限引導、閾值設定
    └── CalibrationOverlayView.kt # 校準精靈用的全螢幕框選/點選畫布
```

**為什麼不硬編碼座標／顏色？** 因為每個人的裝置解析度、遊戲 UI 版面、私服畫面都不同，硬編碼對你的環境不見得有效。所以所有「HP 血條在哪」「攻擊鈕在哪」都透過 App 內的**校準精靈**（拖曳框選 / 點選）由你自己指定，存成 JSON 設定檔。

## 判讀原理（重要限制）

`BarReader` 不是 OCR，而是簡單的色彩比對：
- **血條／魔力條**：校準時你框選「滿血/滿魔力」狀態下的矩形，系統記錄該區域中線的顏色；執行時逐像素比對顏色相似度，算出「符合滿血顏色」的像素比例，當作百分比。若你的血條顏色會隨百分比漸層變色、或血條上有文字覆蓋，準確度會下降，可調整「顏色容忍度」或改框選更乾淨的區域。
- **敵人指示區**：校準時你在「沒有敵人」的狀態下框選一塊會變化的區域（例如敵人名條、戰鬥狀態圖示的位置），系統記錄該區域「沒有敵人時」的平均顏色；執行時若該區域顏色偏離這個基準，就判定「有敵人／戰鬥中」。

這代表**每次遊戲改版、UI 版面調整、裝置換了、解析度變了，都需要重新校準**。

## 使用步驟

1. 用 Android Studio 開啟本專案（需要 Android SDK，`compileSdk 34` / `minSdk 26`）。
2. 安裝到裝置後開啟 App，依序：
   1. 授予「顯示在其他應用程式上層」（懸浮視窗）權限。
   2. 到「無障礙設定」啟用 Orna Helper 的無障礙服務（用於模擬點擊）。
   3. 點「授權畫面擷取並啟動服務」，系統會跳出畫面錄製授權對話框，同意後背景服務啟動，畫面上會出現一個可拖曳的小懸浮面板。
3. 切換到你的私服／測試環境畫面，點懸浮面板上的「校準」，依照畫面下方指示，用手指在畫面上框選／點選 7 個項目（HP 血條、MP 血條、敵人指示區、攻擊鈕、HP 藥水鈕、MP 藥水鈕、移動點）。
4. 回到 App 主畫面調整「HP/MP 低於多少 % 自動喝藥」「偵測間隔」「最長執行時間」等參數並儲存。
5. 點懸浮面板上的「啟動」開始自動戰鬥／自動補給；再點一次即可停止。

## 安全機制

- 可設定「最長執行時間」，時間到自動停止。
- 懸浮面板隨時可見、可一鍵停止（不需要回到 App）。
- 停止畫面錄製（例如系統通知列收回錄製）會自動停止整個機器人迴圈。

## 已知限制／可以擴充的方向

- 「移動」目前只是點擊單一固定座標，若你的地圖需要更複雜的路徑（多點巡邏、隨機遊走）可以在 `BotEngine` 裡把 `moveTapPoint` 換成一組座標序列並輪流點擊。
- 色彩比對對於動態光影、半透明特效較敏感，之後可以考慮加入模板比對（bitmap 差異比對）取代單純顏色距離，準確度會更高但運算量也更大。
- 目前假設血條是「純色填滿 vs 空」的簡單樣式；漸層血條可改成分段取樣多個色標。
